# Use page-addressable Markdown derivatives for Codex reading

ResearchOS generates an immutable, page-addressable Markdown derivative for routine Codex reading and search while preserving the original PDF as the authoritative evidence source. The derivative reduces repeated multimodal document processing and supports efficient navigation, but citations always resolve to physical PDF pages and Codex falls back to the original for figures, equations, layout, or degraded extraction; MarkItDown is the Local MVP converter, not a permanent parser commitment.
