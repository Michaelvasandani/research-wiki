# Separate research-chat evidence from wiki evidence

Research chat may use Codex live web search when ingested sources are insufficient, but ingest and wiki-lint writers run without network access and may use only deliberately ingested papers. A filed analysis must omit externally sourced claims unless the researcher first ingests their evidence. This workflow-specific network policy preserves Codex's broader research capabilities without allowing external results to silently enter the lab's persistent evidence base.
